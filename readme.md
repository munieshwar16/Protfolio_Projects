## 📂 Projects Overview

### 🧠 Content Writing Agent
> A multi-agent pipeline that scrapes AI news, classifies topics, performs research, and auto-generates well-structured content with fact-checking and publishing readiness.
- 🛠️ Tools: Python, LangChain, FastAPI, Hugging Face
- 💡 Features: Modular agents, LLM orchestration, real-time article creation

### 🛡️ Employee Behavior Recommender System
> A PySpark-based anomaly detection and recommendation system analyzing login, file, and web access patterns to improve security posture in enterprises.
- 🛠️ Tools: PySpark, Power BI, Isolation Forest, ALS
- 📊 Output: Risk flags + behavioral suggestions

### 💤 Driver Drowsiness Detection
> Real-time deep learning system that detects eye states and triggers alarms to prevent road accidents due to fatigue.
- 🛠️ Tools: OpenCV, Keras, CNN, Haar cascades
- 📈 Trained on 7000+ images with live webcam demo

### 💬 Medical Recovery Assistant (RAG)
> Domain-specific RAG system built for post-surgical guidance using scraped hospital content and guideline PDFs.
- 🛠️ Tools: LangChain, ChromaDB, Solar, LLaMA, Phi-2
- 🔎 Retrieval: Hybrid TF-IDF + embeddings + reranker
- 📄 Outcome: Reliable recovery insights with ROUGE-evaluated accuracy

### 🎨 Neural Style Transfer
> A computer vision pipeline that applies artistic styles to user-uploaded photos using deep convolutional networks.
- 🛠️ Tools: PyTorch, VGG-19
- 🖼️ Output: Stylized images in the form of artistic portraits

### 🌌 Dream Reconstruction AI
> Converts narrated dream descriptions into cinematic or 3D experiences using scene extraction, image generation, and Unity rendering.
- 🛠️ Tools: Mistral, DreamShaper, Hugging Face, Unity
- 🎬 Outcome: Dream scenes as images and immersive environments
